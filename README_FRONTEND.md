# DisplayAds — Frontend & Web Dashboard (consolidated)

This file is the canonical README for the web dashboard (React + Vite).

Quick start
- cd Workspace
- npm install
- npm run dev (http://localhost:5173)

Build for production
- npm run build
- Serve the `dist` output with any static server or container image.

Key notes
- Ensure VITE_API_BASE_URL points to the API server.
- If using Traefik, adjust labels in `docker-compose.prod.yml` and route your domain.

Archived docs
- Old marketing, pitch, and duplicated README files were consolidated into this one. Originals moved to docs/archived_markdown/ for reference.
